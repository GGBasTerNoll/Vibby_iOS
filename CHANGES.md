# Vibby iOS (SwiftUI) — этап 1

Совместимо с Firebase проекта vibby-b1913 (те же пути и форматы, что в Flutter-клиенте).

Готово: вход/регистрация, подтверждение почты, разрешение входа с другого устройства,
список чатов (кэш на диске, закрепление, mute), переписка (текст, фото, стикеры, голосовые,
файлы/видео как вложения, опросы, ответы, реакции, правка, удаление, «печатает», галочки),
E2EE (X25519+HKDF+AES-GCM, совместимо с e2ee.dart, импорт/экспорт ключа), новый чат по логину,
«Избранное», настройки.

Не сделано: создание групп/каналов, push (FCM), запись голосовых/кружков, создание стикеров,
верификация-заявки, загрузка более старых сообщений.

Сборка: push в main → GitHub Actions → артефакт Vibby-ipa (без подписи).
Код не компилировался в песочнице: возможны мелкие ошибки при первом прогоне CI.
